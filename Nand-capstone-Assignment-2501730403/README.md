## Folder Contents

- `CPU.hdl`, `Memory.hdl`, `Computer.hdl` — Part A Hack computer HDL implementation
- `assembler.py` — Part B two-pass Python assembler (`K mod 3 = 0` symbol table export)
- `Box.asm`, `Box.hack` — Part C Hack assembly program & machine binary for `K = 03`
- `symbols.txt` — Label and variable address table generated by `assembler.py`
- `programs/` — Sample test assembly programs (`Add.asm`, `Max.asm`, `Rect.asm`, `Pong.asm`)
- `tests/test_capstone.py` — Automated verification tests for assembler output and `Box.hack`

## Quick Commands

Assemble `Box.asm` and regenerate `Box.hack` and `symbols.txt`:

```powershell
python assembler.py Box.asm
```

Run automated tests:

```powershell
python -m unittest discover -s tests -v
```

## Official Simulator Verification (Required for Report Screenshots)

1. Open the official Nand2Tetris **HardwareSimulator** and test `CPU.tst`, `Memory.tst`, and `Computer.tst` with `CPU.hdl`, `Memory.hdl`, and `Computer.hdl`.
2. Open the official Nand2Tetris **CPUEmulator**, load `Box.hack`, run at Fast speed, press any key to see the 64×20 black box at row 3, and release to erase it.
